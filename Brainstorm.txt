Daily wizard
[
    We are starting the creation of a new subtool called Daily Wizard.

    we are only to create the Agent.MD design spec, and a empty .html
    file for the wizard.  We will not touch the main Agent.MD yet or
    any of the main tools files.  Ask any questions you need and feel
    free to suggest things to help me design this better.

    The main crop labour wizard tool effectively tracks all big jobs
    related to any crop, but it does not cover daily essential activities
    (Watering plants, Mixing fertilizer, Scouting rooms, Stocking paper towel,
    Stocking uniforms, Stocking glove holders, etc)
    The purpose of this tool is to generate daily todo lists for
    each building, with the ability to see a combined list for all buildings on site.
    The wizard should allow you to build daily task lists that get saved directly
    to the wizards database key. 

    When creating a task, the user should be able to pick a emoji from
    a full emoji picker, set a name for the task, estimated time, and
    required staff.  After setting all daily tasks for the building,
    the wizard should look at the main database calendar events and Put
    any events for that building that day below the main daily tasks as
    well.

    Tasks should be able to either be checked off, or pressed on to go into 
    a detailed view of that task where the manager can put step by step
    instructions.  Tasks should be able to be moved up and down.
    Pictures can be saved next to the html file in a subfolder
    called pics that you can use the tasks unique code (4 letter code) with A
    underscore and a number (j234_1.png, j234_2.png), then when making detailed
    instructions for that task they can be loaded as a picture for that step
    (Step 1 j234_1.png, Step 2 j234_2.png).  

    The tool should follow all the standard UI conventions and theming
    as other subtools, but this one is slightly special as it will be
    designed to sometimes be launched stand alone.  It will be used on 
    tablets in the buildings by staff to coordinate daily happenings.
    It should just have a large check box next to each task that employees
    can easily check off with their thumb on a tablet screen.  the daily
    wizard does not need to alter the main database when used this way to
    mark tasks as completed, it is purely for staffs informational purposes
    and the floor manager to direct staff effectively on a day to day.
    in the future we may incorporate labour tracking into the calendar but
    for now we want a simple to-do list that shows the dailies for that building
    and after that any scheduled crop tasks for that day in that building
    with a simple UI to check things off that matches the overall
    look of the rest of the suite.
]
