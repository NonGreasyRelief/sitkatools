Close out tool
[
  We are going to start the creation and design of a new subtool called
  the Close Out tool.

  The purpose of the close-out tool is to archive all information related
  to a lot that has been completed out (All calendar events have passed,
  and the lot has been harvested or destroyed).  When a lot is closed out,
  all of its data gets written to a json file with the date and lots number.
  The user then saves all of these to a designated folder on the company
  sharepoint.

  The close out tool should also have the ability to combine closed out lots
  into a "finished_lots_db.json", or save them as individual jsons.

  Once a lot has been fully captured into the finished_lots_db.json or
  the lots individual json, the tool deletes all of that lots events
  and removes all its keys from the main DB to keep the Active DB lean
  but not lose all the information we've tracked.
]
