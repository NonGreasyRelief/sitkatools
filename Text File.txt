Demo Talking Points for CEO
Unified Calendar View — All modules feed one timeline. See IPM orders, labour jobs, clone schedules, fertilizer needs, sales deadlines, compliance dates, and equipment maintenance in a single interface
Decoupled Architecture — Each module only writes its own data (_tool_<Name> keys) but contributes to the shared calendar. Adding a new module requires zero changes to SitkaTools
Drag-and-Drop Rescheduling — Move any event directly on the calendar grid
Event Details Panel — Click any event to see assigned teams, estimated hours, notes, and source module
Extensible Design — New modules (SalesTracker, ComplianceTracker, etc.) just append events with their own sourceTool — no changes needed to existing tools
